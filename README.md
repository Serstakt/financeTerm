# Financial Terminal

Финансовый терминал для отслеживания котировок, управления портфелем и алертами.

## Стек
- **Backend:** Python 3.11+ + FastAPI
- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript
- **Database:** SQLite
